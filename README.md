# 🏫 SNU Campus Exchange

> Every place on campus has a live pulse: crowd, people, and lost & found.

**Track:** Campus Reimagined

## AWS Services

| Service | Purpose |
|---|---|
| **AWS Amplify** | Static site hosting |
| **AWS Lambda** | Serverless backend (Python 3.12) |
| **API Gateway** | HTTP API with CORS |
| **DynamoDB** | 5 on-demand tables (Players, Checkins, Profiles, Memberships, Waves) |
